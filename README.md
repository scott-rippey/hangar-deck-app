# Hangar Deck for Builders

The launcher for the Power Your Process Mac apps. One window and a menu bar
item that show every app, whether it is installed, and whether a newer
version is out; install and update them from here; get told when something
new lands.

Apps it manages today: CC Blackbox, Model Radar, and Hangar Deck itself. New
apps appear here automatically; nothing to reinstall.

## Install

Download the latest DMG from the Releases page, open it, and drag Hangar Deck
to Applications. Requires an Apple Silicon Mac on a recent macOS. The app is
signed and notarized.

## Safety

Every download is verified against the published checksum and against
Apple's Developer ID signature for Power Your Process before it is installed.
Nothing is uploaded; there are no accounts and no telemetry.
